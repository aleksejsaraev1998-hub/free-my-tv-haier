# Что даёт Free My TV на Haier FF Pro

Добавлен отдельный [Bento Preview](bento-preview.md). Ниже описаны исходные Standard/Lite; особенности нового экрана и календаря CalDAV — в отдельном документе.

## Главное

Это замена домашнего интерфейса, а не новая прошивка Android. Сейчас подготовлены две изолированные Preview: они запускаются как обычные приложения. Штатный лаунчер остаётся установленным, включённым и назначенным на Home. Системные изменения не выполняются.

## Функции и ограничения

| Возможность | В наших Preview | Что нужно учитывать |
|---|---|---|
| Чистый домашний интерфейс без рекламных рядов | Да | Не удаляет рекламу внутри YouTube, браузера и других приложений |
| Полка приложений: выбрать нужные, порядок, запуск | Да | Установленные приложения остаются прежними; совместимость запуска проверим на ТВ |
| Браузер | Отдельная кнопка запуска в полке и нижнем меню | Открывает установленный браузер; без встроенного WebView. Если подходящих несколько и системный выбор не определён — показывает выбор. Если ни одного нет — сообщает об этом |
| Список всех доступных приложений | Да | Видимость зависит от Android и наличия launcher activity у приложения |
| Русский интерфейс | Да | Используется каталог переводов upstream |
| Светлая, тёмная, автоматическая тема | Да | Автотема учитывает время восхода/заката для выбранного города |
| Погода, часы, дата | Да | Погода требует интернета; по умолчанию Челябинск, можно выбрать другой город |
| Настройка верхних кнопок и полки | Да | Только внутренний интерфейс Free My TV |
| Открытие системных настроек и ТВ-входов | Предусмотрено исходниками | Конкретные HDMI, эфирное ТВ и возврат из них проверим на Haier; это не новый драйвер входов |
| Рекомендации фильмов/сериалов | Выключены без ключа TMDB | Можно подключить позже; наличие сервиса, регион и API влияют на результат |
| Часы и фотографии в заставке | Есть ручной предпросмотр | Системная заставка не заменяется; импорт своих фотографий в отдельный Preview-пакет ещё не адаптирован |
| Криптовалюты | По умолчанию выключены | Это необязательная функция upstream, не преимущество для этой задачи |
| Переназначение физических кнопок пульта Haier | Не заявлено | Поддержка отдельных брендов в upstream не подтверждает поддержку Haier; системная accessibility-служба здесь не включается |
| Работа Free My TV по кнопке Home, автозапуск после включения | Нет в Preview | Это следующий этап после испытаний и отдельного согласования |
| Автоматический деблоат | Заблокирован | Ни один системный пакет не отключается |

Приложение не даёт бесплатные подписки, не меняет кодеки/драйверы, не увеличивает физическую RAM, не ускоряет интернет и не гарантирует более плавное видео в сторонних приложениях.

## Standard и Lite

Оба APK универсальные Java/Dex, без .so, подходят для armeabi-v7a. У них разные package ID, поэтому можно установить оба для сравнения:

- Standard: io.freemytv.haierpreview
- Lite: io.freemytv.haierpreview.lite

| Параметр | Standard Preview | Lite Preview |
|---|---|---|
| Сложные AGSL-эффекты фона/стекла | Как в upstream, если поддержаны GPU | Не создаются; используется готовый упрощённый путь отрисовки |
| Запрос кадров при активной анимации главного экрана | На каждый VSync | С задержкой минимум 33 мс; фактическая частота зависит от дисплея и нагрузки |
| Фоновые изображения и карточки Backdrop | До размеров UI, максимум 1920×1080 для фона | Размеры ограничены масштабом 2/3, максимум 1280×720 для фона |
| Экран настроек в покое | Частый кадровый callback, периодическая перерисовка | Callback примерно раз в секунду; при анимации — с задержкой 33 мс |
| Предпросмотр заставки | Механизм upstream с отрисовкой около 20 кадров/с | Callback с задержкой 100 мс, примерно до 10 кадров/с |
| Обновление погоды при открытом интерфейсе | Не чаще 30 минут | Не чаще 60 минут |
| Реклама, криптовалюты, TMDB без ключа | Рекламы интерфейса нет; криптовалюты/рекомендации выключены | То же |

Lite намеренно проще визуально; анимации могут выглядеть менее плавными. Ограничение картинок не снижает системное разрешение HDMI/экрана и не влияет на качество видео в других приложениях. Если UI уже 720p, ограничение размеров не даст такого же выигрыша, как при 1080p. Точный расход памяти требует измерений.

## Чем лучше штатного экрана

Подтверждённые преимущества самого интерфейса: отсутствие встроенных рекламных рядов, управляемая полка приложений, русский язык и выбор темы. Lite дополнительно уменьшает вычислительную работу собственных эффектов и пределы размеров собственных изображений. Насколько удобнее это именно владельцу Haier, проверяется использованием.

Потенциальный выигрыш в общей RAM появится только если проверенный Free My TV впоследствии станет домашним экраном и штатный лаунчер перестанет занимать прежнее место в фоне. Сейчас оба приложения могут оставаться в памяти, поэтому установка Preview сама по себе способна увеличить суммарное потребление.

В исходном снимке PSS штатного лаунчера — 115 404 K, рекомендаций — 35 626 K. Это не обещание освободить их сумму: память общая/динамическая, часть процессов может остаться, а новый экран тоже потребляет RAM. Измерение upstream на TCL (96 против 242 MB) нельзя переносить на Haier.

## Как подтвердим результат на ТВ

1. Восстановить ADB, определить текущий Serial и снять исходный снимок в штатном экране.
2. После согласования установить Preview, не назначая HOME. По очереди открыть Standard и Lite, дать каждому 60 секунд на загрузку, одинаково пройти по полке и меню.
3. На одном и том же устройстве сравнить PSS всех процессов соответствующего пакета, GPU/графическую память и статистику кадров. Отдельно проверить отклик кнопок. Показатель PSS одного процесса нельзя выдавать за общую память телевизора.
4. Проверить Home/Back, звук, запуск нужных приложений, HDMI, эфирное ТВ и возврат в штатный экран.
5. Убедиться, что HOME и список отключённых пакетов остались прежними. Проверить работу без интернета: приложения доступны, свежая погода/онлайн-рекомендации — нет.

Для снимков есть tools/measure-preview.ps1. Скрипт только читает диагностику, ничего не устанавливает и не переключает. Пример после проверки текущего адреса:

```powershell
.\measure-preview.ps1 -Serial 'АКТУАЛЬНЫЙ_IP:ПОРТ' -Profile stock
.\measure-preview.ps1 -Serial 'АКТУАЛЬНЫЙ_IP:ПОРТ' -Profile standard
.\measure-preview.ps1 -Serial 'АКТУАЛЬНЫЙ_IP:ПОРТ' -Profile lite
```

Сначала открывать соответствующий экран вручную, затем снимать его снимок. Это не автоматический бенчмарк. framestats без reset накапливает историю процесса: для сравнения брать сопоставимые участки/дельты, а не сравнивать сырые счётчики от разных сессий.

После этих испытаний можно выбирать между сохранением штатного экрана и отдельным согласованным этапом замены HOME. Полный режим upstream не включён ни в одной Preview.

## Браузер в Preview.3

Кнопка «Браузер» добавлена в обе версии. Она ищет включённые приложения, которые объявляют себя браузером или обрабатывают обычные http/https ссылки и имеют запускаемый главный экран. Используется выбранный системой браузер, если он входит в этот список; иначе единственный найденный или системное окно выбора. Если браузеров нет, появляется сообщение с просьбой установить браузер для Android TV. Приложение ничего не скачивает и не устанавливает автоматически. Пробный URL применяется только для поиска обработчиков: страница не открывается и запрос к ней не отправляется.

Иконка глобуса рисуется примитивами Canvas, без новых изображений и выделения объектов при отрисовке. В APK добавлены только правила видимости браузеров, без дополнительных разрешений. Закладки и история принадлежат самому браузеру; панели закладок в лаунчере пока нет. VPN по-прежнему управляется отдельным клиентом и его правилами маршрутизации. Возврат по Back зависит от поведения установленного браузера и требует проверки на ТВ.
