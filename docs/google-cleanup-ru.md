# Обратимое отключение необязательных Google-приложений на Haier

Скрипт `tools/disable-haier-google-extras.ps1`, Windows PowerShell 5.1/PowerShell 7 + существующий adb.exe. Новые Git, Java или Android SDK на компьютере не нужны. Это отдельная операция ADB, приложение Bento по-прежнему не имеет транспорта изменения системных пакетов.

Владелец разрешил отключить голосовой Google-ассистент и ненужные Google-компоненты, отказавшись от новых замеров RAM. Исходная диагностика подтверждает com.google.android.katniss и его процессы interactor/search. В upstream HomeMode.ASSISTANT также предусмотрено опциональное отключение katniss/hotwordenrollment. Скрипт не утверждает конкретный выигрыш памяти и не измеряет её.

## Закрытый список кандидатов

- com.google.android.katniss — ассистент/голосовой поиск Google.
- com.android.hotwordenrollment.okgoogle и com.android.hotwordenrollment.xgoogle — настройка ключевой фразы, если установлены.
- com.google.android.youtube.tv — YouTube для ТВ.
- com.google.android.youtube.tvmusic — YouTube Music.
- com.google.android.play.games — Play Games.
- com.google.android.videos — Google TV / Play Фильмы.

Отключаются только найденные для user 0 кандидаты в состоянии default/enabled, прошедшие автоматические проверки. Существующие disabled/disabled-user/disabled-until-used сохраняются. Любой иной пакет запрещён на границе функции изменения состояния, включая при откате.

После отключения недоступны Google-ассистент/голосовой поиск и перечисленные медиаприложения; связанные кнопки пульта могут перестать запускать соответствующую функцию. Это ожидаемое последствие. Распознавание в сторонних приложениях может зависеть от Google и потребовать отдельной проверки. Наш календарь SOGo/ICS использует прямой HTTPS и не вызывает Google-ассистент.

## Что сохраняется

Google Play, Play Services, Services Framework, экранная клавиатура, Android TV Remote Service, Cast, системный WebView, Permission Controller/установка пакетов, системные службы, сеть, первоначальная настройка, штатный HOME и tvrecommendations. Не выключаются TTS/голосовая клавиатура и Google Calendar Sync, зависимости которых не проверены для всех установленных приложений.

Штатный launcher и его рекомендации оставлены, поскольку кнопка Home пока возвращает на штатный экран, а Preview ещё не является домашним приложением с проверенным аварийным возвратом. Нельзя отключать все com.google.* по маске: среди них магазин, клавиатура, разрешения и другие необходимые службы.

## Запуск

Сохранить скрипт рядом с `C:\platform-tools\platform-tools\adb.exe`.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\disable-haier-google-extras.ps1 -Mode Apply -TV 192.168.1.215:45053
```

Если Wi-Fi ADB сменил порт, указать актуальный `-TV`. PowerShell ExecutionPolicy меняется только для этого запуска процесса, постоянная политика системы не меняется.

Режим по умолчанию Inspect: показывает план без изменений. Apply автоматически проверяет model Haier / device daan, текущий user 0, действующие HOME и клавиатуру, исходные состояния защищённых пакетов и метаданные кандидатов. Пакеты, связанные с ТВ-входами, кнопкой выбора входов, сопряжением пульта, persistent/system UID, пропускаются. Ошибка чтения останавливает выполнение до изменений.

Скрипт создаёт отдельную папку `haier-google-backup-<дата-время>`, не перезаписывая прежний restore-haier.ps1. В ней journal.json, копия текущего скрипта и restore-google.ps1. Журнал фиксирует намерение **до** каждой мутации, чтобы восстановление осталось возможным после потери ADB/закрытия окна. Папка остаётся только на компьютере владельца, не загружается в GitHub.

Для каждого выбранного пакета выполняется только `pm disable-user --user 0`, затем проверяется реальное состояние. Нет uninstall, clear, изменения разрешений/сети/HOME, удаления данных, автоперезагрузки и изменения серверных календарей. По окончании повторно сверяются HOME, клавиатура и состояния защищённых пакетов. При ошибке пытается автоматически вернуть все затронутые пакеты; если связь потеряна, локальный откат остаётся доступен.

## Откат

В конце выводится точная команда запуска restore-google.ps1 из созданной папки. Например:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\haier-google-backup-YYYYMMDD-HHMMSS-fff\restore-google.ps1
```

При новом порте добавить `-TV <актуальный IP:порт>`. При перемещении adb.exe можно также передать `-AdbPath <полный путь к adb.exe>`.

Откат восстанавливает исходные enabled states: default → pm default-state, enabled → pm enable. Проверяется модель/плата/аппаратный serial из журнала, если он доступен. Это откат состояний только затронутых пакетов, не полный образ прошивки и не возврат сторонних изменений, сделанных после запуска.

## Проверки и ограничения

`tests/test-google-cleanup.ps1` использует полностью подменённый ADB: никакого доступа к реальному ТВ. Проверяет синтаксис, Inspect без мутаций, allowlist, зависимость TV_INPUT_HARDWARE, пропуск отсутствующих/уже выключенных пакетов, файл отката, точное восстановление состояний 0/1, автоматический откат при сбое после мутации, отказ на другом устройстве и отказ изменять GMS. GitHub Actions запускает тесты на Windows PowerShell 5.1 и PowerShell 7.

Проверки метаданных уменьшают риск, но не доказывают все скрытые зависимости прошивки Haier. Реальное отключение и работа магазина/клавиатуры/пульта после него ещё должны быть проверены владельцем. Нет обещания измеренного ускорения или фиксированной экономии RAM.
