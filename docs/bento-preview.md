# Bento Preview — первый перенос на Android

Отдельный пакет `io.freemytv.haierpreview.bento`. Lite остаётся рядом, его не нужно удалять. Bento запускается как обычное приложение: системный HOME, автозапуск и отключение пакетов не включены. Физическое разрешение Haier 3840×2160 с существующим override 1920×1080 не меняется.

## Реализовано

- Сетка 1920×1080 с внешними отступами 40, внутренними 40, зазорами 24; адаптация единым масштабом к размеру окна без изменения системного разрешения.
- Ночная палитра по согласованному эскизу. Дата в две строки, часы над минутами; цифры размещаются по Paint.getTextBounds.
- Один Canvas: без полноэкранных картинок и шейдеров, без отдельных аппаратных слоёв плиток. Нет цикла кадров в покое; часы меняются раз в минуту. Фокус анимируется ValueAnimator только после ввода, без прежнего ограничения Lite в 33 мс. Плитка растёт на 4%, приложение — на 6%.
- Погода MET Norway Locationforecast, без ключа: температура ближайшего прогнозного шага, описание, диапазон следующих 24 часов. Это прогноз, а не измеренная температура/наблюдённые минимум и максимум дня. По умолчанию город Челябинск; изменить можно в настройках Free My TV. Доступность API из сети владельца ещё нужно проверить. Источник: https://api.met.no/weatherapi/locationforecast/2.0/documentation (MET Norway, CC BY 4.0).
- Курсы USD/EUR к рублю из cbr-xml-daily.ru, дата курса из ответа, стрелки относительно предыдущего опубликованного курса. Источник данных — ЦБ через сторонний сервис. Не чаще раза в час; при ошибке — повтор не раньше двух минут. Цифры не выдумываются: без ответа показываются прочерки, кэш отмечается.
- «Сегодня»: локальные задачи сохраняются после закрытия/перезагрузки. OK на плитке открывает список; OK на задаче переключает выполнение. Можно добавить задачу и удалить выполненные. Время в начале, например `18:30 Купить продукты`, необязательно. `!` в начале отмечает срочную. До 8 задач — одна колонка; больше — две сбалансированные. Длинный текст — до двух строк с многоточием. Выполненные идут последними и скрываются первыми при нехватке места; внизу — число скрытых и время изменения. Лимит хранения — 100 задач.
- «Тезис недели»: OK открывает локальное редактирование. Текст сохраняется, на плитке до трёх строк. Никакой демонстрационной цитаты в APK нет.
- Кнопки Телеканалы / Входы HDMI / Настройки. ТВ-входы определяются средствами upstream; работу на Haier ещё проверить. Внешние настройки запускаются только по нажатию.
- Полка: до четырёх выбранных приложений плюс Браузер, VPN и Все приложения. Приложения выбираются в Настройки → Полка, по порядку выбора. Миниатюры готовятся в фоне, максимум 240×96, приглушаются по средней яркости. Браузер остаётся отдельным приложением.
- VPN открывает установленный Happ или v2RayTun, при наличии обоих предлагает выбор. Не подключает туннель, не импортирует подписку, не отображает неподтверждённый статус.
- Back на главном экране закрывает Bento. Home остаётся у штатного лаунчера. На основном экране настроек Free My TV Back явно завершает SettingsActivity.

## Пока не входит в эту сборку

- Сетевой сервер `/board`, удалённая загрузка задач и QR-подключение доски. Сейчас доска редактируется с пульта и хранится только на ТВ.
- Замена системного HOME/заставки и проверенный аварийный возврат из полноценного режима. Поскольку это Preview с блокированным ADB, watchdog не может переназначать системный HOME; назначать Preview домашним экраном вручную не следует.
- Автоматическое включение VPN, полноценный браузер внутри лаунчера и реклама внутри сторонних приложений.

## Проверки и пределы

`tools/test_bento_layout.py` компилирует реальный BentoLayout и проверяет геометрию. `tools/verify_preview.py` проверяет package/разрешения/подпись/отсутствие HOME, boot hooks и нативных .so, заглушку ADB, использование BentoView и отсутствие собственных аллокаций непосредственно в onDraw. Вызовы Android внутри отрисовки могут иметь собственные внутренние затраты; это не доказательство нулевых аллокаций всего render pipeline.

Рендер Android, читаемость шрифтов на расстоянии, обрезка длинных строк, подсветка и навигация пультом, работа трёх кнопок и память требуют проверки на физическом ТВ. Проверка геометрии исходников не подменяет замер скриншота реального устройства. Фактический расход RAM новой Bento ещё не измерен.

## Откат и подпись

Старый код закреплён в ветке `backup/pre-bento-preview-3`; последний проверенный старый CI-run: https://github.com/aleksejsaraev1998-hub/free-my-tv-haier/actions/runs/40099086900. Старый скачанный APK на компьютере владельца не перезаписывается, новый называется иначе. Самый простой возврат — закрыть Bento и открыть уже установленную Lite.

Сборки Actions без секрета имеют временный ключ на каждый запуск. Они могут не обновляться поверх локального APK. Для дальнейших обновлений нужно использовать тот же ключ; ключи не хранятся в репозитории. Ошибку подписи не следует решать удалением пользовательских данных без согласования.

## Проверка после установки

Открыть Bento отдельно, пройти стрелками все плитки и полку. Проверить задачи и тезис после закрытия/повторного запуска. Проверить отсутствие выдуманных данных без сети, запуск имеющихся приложений, браузера, HDMI и настроек. Сравнить память при чистом запуске и после меню, явно указывая процесс `io.freemytv.haierpreview.bento:home`. Системные компоненты при этих проверках не отключаются.
